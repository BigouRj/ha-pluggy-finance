# Pluggy Finance

Projeto inicial para uma integração customizada do Home Assistant para Pluggy Finance.

## Estrutura

- `custom_components/pluggy_finance/`: código da integração.
- `hacs.json`: configuração do HACS.

## Como começar

1. Copie a pasta `custom_components/pluggy_finance` para a pasta `custom_components` do seu ambiente Home Assistant.
2. Reinicie o Home Assistant.
3. Adicione a integração via Interface de Usuário (UI).

## Observações

Este projeto ainda está em fase inicial. Ajuste os campos de autenticação, endpoint e sensores conforme a API real do Pluggy Finance.
